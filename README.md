# java-fundamentals-and-practice
Repositório dedicado ao aprendizado, prática e evolução em Java, reunindo exercícios, exemplos e implementações desenvolvidos ao longo de uma jornada de estudos da linguagem. O conteúdo é baseado na Maratona Java Virado no Jiraya, abrangendo desde os fundamentos da linguagem até conceitos avançados do ecossistema Java.

##  Objetivo

Este repositório tem como objetivo consolidar conhecimentos em Java por meio de prática contínua, organização dos estudos e implementação dos conceitos apresentados durante a formação.

Além de servir como material de estudo e consulta, o projeto documenta minha evolução no desenvolvimento utilizando Java.
